# Recova API

FastAPI backend template with versioned routing, environment configuration, CORS, lifespan hooks, and health endpoints.

```bash
uv run fastapi dev main.py
```

Docs: `http://localhost:8000/docs`

Endpoints: `GET /`, `GET /api/v1/health`, `GET /api/v1/health/ready`.

Copy `.env.example` to `.env` and adjust values.
